# s01 — the coffee-pot café

**Feature:** the café exists. A coffee-pot building outside, a dollhouse corner room inside, and four camera modes (outside, dollhouse, walk, barista POV) that glide between each other.

**Lines worth showing** (`src/world/Exterior.tsx`): a whole building from one curve.
```ts
const POT_PROFILE = [[4.9, 0], [5.9, 1.2], [6.2, 2.8], [5.95, 4.4], [5.3, 5.8], [4.8, 6.5]]
const curve = new THREE.SplineCurve(POT_PROFILE.map(([r, y]) => new THREE.Vector2(r, y)))
return new THREE.LatheGeometry(curve.getPoints(40), 48) // spin the curve = a pot
```
Concept: a **lathe**, the same idea as a potter's wheel. Draw half the outline, spin it.

**What broke:**
1. v1 looked boxy and brown ("ugly"). Restyled to a pink/purple/mauve candy palette, swapped every box for rounded boxes, and added busy props.
2. The barista POV camera sat *behind* the back wall. Fix: in POV the back wall is cut away, like a dollhouse.
3. The FPS read 1 because the browser pane was hidden (browsers throttle hidden tabs). It wasn't the game. 46 fps when visible on UHD 620.

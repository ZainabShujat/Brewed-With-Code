# s06: the cake bench

**Feature:** a cake station in the kitchen (camera mode 5). You get a cake order, then:
1. stack sponges (vanilla / chocolate / strawberry): each drops onto the turntable with a little settle
2. add a filling between layers (cream / jam)
3. pour frosting (pink / white / chocolate / lavender): it flows down from the top, then drips run down the sides
4. pipe rosettes (white / pink / chocolate): 14 appear one by one around the rim as the turntable spins
5. top it (sprinkles rain down, or cherries / strawberries / candles pop on)
6. box it: scored against the order (−20% per wrong detail), coins + a tip for perfect

**Lines worth showing** (`src/world/Cake.tsx`): animation from a timestamp, no animation library.
```ts
// every part remembers when it was added; each frame just asks "how long ago was that?"
const k = clamp01((now() - t0 - i * 0.11) / 0.25)   // rosette i starts 0.11 s after rosette i-1
rosette.scale.setScalar(k)
```
Concept: **time-based animation**. Store *when* something happened, derive *how far along it is* every frame.

**What broke:** sprinkles landed in a perfect ring (I'd placed them with a golden-angle formula that bunched up). Now a hash scatters them like real sprinkles. Frosting drips stuck out like pills, so they were flattened and sunk in.
